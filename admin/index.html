PERSONAL Y APROBACIONES

Actualizar un pasaporte

Busca por cédula para registrar una persona, corregir su nombre o añadir cursos aprobados. El historial del Excel se conserva; las actualizaciones manuales sobreviven a las siguientes importaciones.

Aprobaciones añadidas desde este panel

Añadir a la lista prepara el cambio. Pulsa Guardar persona para publicar el nombre, el estado y las aprobaciones. Retirar una aprobación manual no elimina la que ya exista en el Excel.

Cómo se interpreta el archivo

  • Solo se incluyen filas con percAprob = 100.
  • Una cédula + un ID de capacitación = un curso único. Se conserva la fecha de finalización más reciente.
  • La insignia usa la URL de la fila; si está vacía, se busca por ID en la pestaña Insignias. Las imágenes repetidas cuentan una sola vez por persona.
  • El avance compara los cursos únicos completados con los cursos únicos válidos de Archivo Plano. No se inventan cursos pendientes ni fotografías.
